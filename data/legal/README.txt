Terms of Service / Privacy Policy screens
=========================================

terms_of_service.txt   Terms of Service text
privacy_policy.txt     Privacy Policy text

Plain text. The server reads the file each time the screen opens (no restart
needed) and writes the default text again when a file is missing.

Per language: terms_of_service.<LANG>.txt / privacy_policy.<LANG>.txt, where
<LANG> is the language code the game sends, letters and digits only (for
example ptBR). The server log shows the code. Without such a file the plain
one is used.
